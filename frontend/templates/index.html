Sobre o projeto

Este mapa reúne ocorrências criminais registradas a até 50 metros de pontos de ônibus em São Paulo, para ajudar a identificar os trechos de maior risco para quem usa o transporte público.

Os pontos azuis são paradas de ônibus e os vermelhos, ocorrências. Clique em qualquer ponto para ver os detalhes e use o filtro de ano para comparar os períodos. Os dados mostram apenas as ocorrências que foram registradas.
